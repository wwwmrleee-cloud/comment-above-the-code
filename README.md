One funny, painfully honest line imagining the comment a developer left above fragile production code — 118 characters, one line, nothing else:

> Yes, this is a sleep() in production. The API it calls takes 40 seconds. We have a ticket from 2018. It is still open.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The program self-checks the line against the scorer's gate before writing: 1–200 characters, a single line, not only white space.
